Version: v1
Timestamp: 2026-05-14T00:00:00Z

Claim-Level: ROADMAP

## Hidden orchestration UX
- User sees single coherent conversation.
- Internal multi-agent/runtime actions remain transparent only via trust panel, not noisy by default.

## Continuity preservation
- Thread/session continuity markers (`session_id`, last verified state).
- Graceful recovery prompts after interruption.

## Mobile-first flow
- Short action cards, low-friction confirmation, compact status chips.
- Offline/retry hints for unstable networks.

## Onboarding reduction
- 3-step onboarding: purpose -> trust model -> first successful action.
- Remove jargon from first-run UX.

## Trust-oriented messaging
- Always display claim level for critical assertions.
- Separate LIVE vs TESTNET context visibly.

## Session restore UX
- One-tap restore to last known verified checkpoint.
