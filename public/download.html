1. Aplikacja (PWA) — dla użytkowników Rekomendowane

To jest apka do codziennego użytku. NIE ma pliku .exe ani .apk w sklepie — instalujesz ją prosto z przeglądarki (PWA). Po instalacji działa jak aplikacja natywna i synchronizuje się automatycznie (to cienki klient huba — dane żyją w federacji, nie tylko na twoim urządzeniu).

Windows (Edge / Chrome)

Otwórz chat.k0nsult.cloud → kliknij ikonę „Zainstaluj” w pasku adresu (lub menu ⋮ → Zainstaluj aplikację).

Android (Chrome)

Otwórz chat.k0nsult.cloud → menu ⋮ → „Zainstaluj aplikację” / „Dodaj do ekranu głównego”.

Symbian / starsze telefony

Nie wspierane (brak nowoczesnej przeglądarki z obsługą PWA). Alternatywa: bot Telegram @K0nsult_relay_bot.

Otwórz chat.k0nsult.cloud i zainstaluj →
Nic nie pobierasz ręcznie — przeglądarka sama instaluje aplikację z huba czatu.

2. Kod źródłowy — dla deweloperów / własny węzeł Zaawansowane

uni0n v0.3.0 (licencja Apache-2.0) — to KOD ŹRÓDŁOWY rdzenia federacji (serwer w Node.js / TypeScript), a NIE aplikacja-klient. Uruchamiasz go tylko wtedy, gdy chcesz postawić własny węzeł / serwer federacji.

Wymagania (jawnie)

  • Node.js 18+
  • Build TypeScript (tsc)
  • PostgreSQL
  • Redis
  • Zmienne środowiskowe: DATABASE_URL, NETWORK_STATUS, JWT_SECRET oraz klucze providerów modeli

Build w skrócie: npm install → npm run build → node dist/.... Pełne instrukcje w repozytorium.
